# Auto Confirm Dot ⚪

一个简单的自动点击确认工具，拖动圆点到目标窗口，右键启动，每10秒自动点击+回车。

**Author:** zyc

## 适用场景

- Claude Code 多窗口批量任务自动确认
- 需要定期点击确认/提交的场景
- 任何需要重复点击的自动化操作

## 使用方法

### 启动
双击 `start.bat`，屏幕出现**灰色**圆点（默认暂停状态）

### 操作
- **左键拖动**：移动圆点位置（圆点中心 = 实际点击位置）
- **右键点击**：暂停/继续切换
  - 灰色 = 暂停状态
  - 白色 = 运行中
- **双击**：关闭程序

### 多开
支持同时运行多个实例，每个圆点独立工作，互不影响

### 工作原理
1. 记录鼠标当前位置
2. 隐藏圆点窗口
3. 移动鼠标到圆点位置 → 点击 → 按回车
4. 鼠标移回原位 → 点击（回到原来的窗口）
5. 恢复圆点窗口

## 环境要求

- Windows 10/11
- Python 3.6+（确保已添加到系统 PATH）

## 注意事项

- 每10秒执行一次点击+回车
- 标题栏括号内数字为已执行的点击次数
- 关闭程序后不留黑窗口
- 支持多开，窗口位置自动错开

## 常见问题

### 双击start.bat没反应？
检查Python是否安装并添加到PATH：
1. 打开CMD
2. 输入 `python --version`
3. 如果提示"不是内部或外部命令"，需要安装Python或手动添加PATH

### 圆点不动了？
可能是暂停状态（灰色），右键点击切换为运行状态（白色）
